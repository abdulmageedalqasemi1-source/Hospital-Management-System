# 🏥 Hospital Management System Database (Oracle SQL)

مشروع قاعدة بيانات متكامل لنظام إدارة المستشفى، تم تطويره باستخدام **Oracle SQL**.

## 📌 عن المشروع
يهدف النظام إلى تنظيم وإدارة البيانات الطبية والإدارية داخل المستشفى، بما يشمل:
- إدارة بيانات المرضى، الأطباء، والموظفين.
- إدارة المواعيد، السجلات الطبية، والوصفات.
- إدارة الفواتير، الخدمات، والمخزون الدوائي.
- إدارة الغرف، حالات التنويم، والفحوصات المخبرية.

## 📊 المخططات
- **ERD (Entity Relationship Diagram)**: يوضح العلاقات بين الجداول.
- **DFD (Data Flow Diagram)**: يوضح تدفق البيانات بين المستخدمين والنظام.

## 🛠️ التقنيات المستخدمة
- **Database**: Oracle SQL
- **Modeling**: ERD & DFD
